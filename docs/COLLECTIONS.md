# One hundred connected chapter sets

There are exactly 100 addressable chapter themes. Each has a unique name,
independently painted portrait scene, original illustrated card back and playing
table. The first 51 paintings are retained; 49 additional paintings complete the
collection. The first 48 matching back/table pairs are retained and 52 new pairs
complete the same 100-theme order. The classic default back and table remain
available separately. Older unused atlas cells remain for compatibility.

chapter-collection.mjs defines the shared cycle. art-catalog.mjs owns the complete
name list. chapter-worlds.mjs, customization.mjs, Travel Hub, postcards and Card
Studio use this same identity. Chapter 101 begins another journey through the
100 themes; later earned backs still add distinct ornamental seals. The project
does not claim 4,800 independently painted scenes.

New scene sheets: portrait-extra-00.png through portrait-extra-16.png. Three tall
paintings per sheet; only the first column of the final sheet is used. New backs
and tables: chapter-backs-0..3.png and chapter-tables-0..3.png. The first three
sheets use 4×4 grids; the final sheet uses 2×2. These are original imagegen art,
not filter variants or assets from the supplied reference games.

Completing each 100-level chapter earns its matching card back and table. Existing
unlocks retain their IDs. Automatic tables can follow special modes; a manually
selected earned table takes priority. Browser checks render every one of the 100
scenes, backs and tables and confirm all 100 images in each category differ.
