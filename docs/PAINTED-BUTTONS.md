# Painted button surfaces

Created with the built-in imagegen tool. Live labels and icons remain HTML/SVG; CSS nine-slices the paintings to preserve corners at different button sizes.

Assets:
- `web/assets/button-meadow.png` — main actions and purchases.
- `web/assets/button-plum.png` — secondary actions.
- `web/assets/button-parchment.png` — navigation and destination plaques.

Level nodes, the level finder, cards, jewels and side-game board tiles retain their existing art.

Prompts:

## meadow

Use case: stylized-concept. Asset type: production game UI button background for the cozy painted solitaire game Meadow Peaks. A SINGLE horizontal rounded rectangular button plate, front view, sage green enamel with a pale golden rim, tiny carved leaf details in the four corners. Hand painted storybook watercolor and softly shaded tactile carved wood, subtle bevel, restrained highlights, polished casual game art. The button fills the entire image edge to edge, 3:1 landscape composition, rounded corners only at the outer edge. Keep the central 75 percent completely plain, uniform and calm for dark readable live text placed by the game. Details must stay within the outer 10 percent rim. No text, letters, icons, symbols, logos, scene, extra objects, or watermark. Opaque background matching the plate color; no surrounding whitespace. This is one button surface, not a sheet of buttons.
